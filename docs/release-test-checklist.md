# Video Digest 发布前人工验收

版本：________　测试人：________　日期：________

自动门禁全部通过后，Chrome Stable 和 Edge Stable **各完整执行一次**。真实网站和真实模型不放进 CI，避免账号、地区、页面灰度和模型费用导致随机失败。

## 1. 安装与隐私

- [ ] 全新安装正式伴生程序，Chrome/Edge 均能检测到 Native Messaging host。
- [ ] 从商店包或发布 ZIP 加载扩展，标题显示为 `video-digest`。
- [ ] 安装包、扩展 ZIP、日志和导出备份中没有 API Key、Cookie、本机绝对路径、测试媒体、分析资料或未声明二进制。
- [ ] 覆盖安装上一正式版本，设置、笔记、问答历史和本地字幕仍可读取。
- [ ] 静默卸载后程序目录、Chrome/Edge 注册表项和 Native Messaging manifest 无残留；用户主动数据按卸载策略处理。

## 2. Bilibili（登录、未登录各一次）

- [ ] 普通视频、分 P 视频、合集视频及一个此前失败的视频均能显示 Digest 按钮。
- [ ] 人工字幕、AI 字幕、多语言字幕能读取；无字幕、空字幕和接口失败显示明确提示并可重试。
- [ ] 搜索、时间戳跳转、顺句、翻译、概览和笔记保存/编辑/删除正常。
- [ ] SPA 切换视频或分 P 后，标题、字幕、缓存键和播放器跳转都属于新视频。

## 3. YouTube（登录、未登录各一次）

- [ ] 人工字幕、自动字幕、多语言字幕能读取；地区/登录态字幕能够通过页面兜底读取。
- [ ] 无字幕、空字幕和此前失败的视频显示正确错误，不复用上一个视频的数据。
- [ ] SPA 切视频后重新获取字幕，搜索、时间戳跳转、顺句、翻译、概览和笔记正常。

## 4. 侧边栏生命周期

- [ ] A 标签页打开侧边栏，切到同窗口 B 标签页时不显示；切回 A 仍保持打开。
- [ ] 两个浏览器窗口分别维护自己的侧边栏 owner，互不跟随、互不关闭。
- [ ] A 标签页刷新、扩展 Service Worker 休眠/重启后仍保持；浏览器关闭并恢复会话后状态合理恢复。
- [ ] 关闭 owner 标签页或窗口后不会把陈旧 owner 绑定到别的标签页。

## 5. 大模型功能

- [ ] OpenAI 兼容、Anthropic、DeepSeek 各完成一次概览和连续问答。
- [ ] “大模型回答”是自然组织的 Markdown 长回答；“定位字幕片段”只返回紧凑字幕证据，两种样式明显不同。
- [ ] 引用时间戳可跳转且与正文匹配；恶意字幕中的 HTML/脚本只按文本显示。
- [ ] 同一视频的连续 LLM 回答复用上下文，供应商日志或响应指标可观察到缓存命中/输入 token 降低。
- [ ] 取消、超时、限流、无效密钥、服务端错误均有可恢复提示，重试不会产生重复回答。

## 6. 桌面伴生程序与真实引擎

- [ ] 模型下载显示进度，SHA-256 错误会拒绝安装；重启后已下载模型仍可用，卸载模型正常。
- [ ] 使用仓库 `tests/fixtures/engine-acceptance.mp4`：OCR 两行均识别且起始时间误差 ≤1 秒，ASR WER ≤30%。
- [ ] OCR、ASR、双轨三种模式各运行一次；暂停后实际子进程停止推进，恢复后继续，取消后无残留子进程和 `.tasks` 临时文件。
- [ ] 结果可编辑并在重启后保留；SRT、VTT、ASS 导出时间顺序和文本正确。
- [ ] 删除/损坏模型、损坏引擎 manifest、媒体消失、磁盘空间不足时给出明确错误，不崩溃。
